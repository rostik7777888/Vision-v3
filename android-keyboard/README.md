# fishka typing 1.9.4

Быстрая Android-клавиатура с локальным персональным T9.

## Исправление Backspace и проверка слов

Найден и воспроизведён конкретный сбой после обучения нескольким словам:
`ConcurrentModificationException` в подборе подсказок. Чтение частоты слова
меняло порядок той же карты, которая в этот момент перебиралась. Теперь чтения
не изменяют порядок; регрессия проверяет удаление префиксов и восстановление
личного словаря после перезапуска. Ошибка фонового запроса также не завершает IME.

Проверка опечаток остаётся локальной: словарная частота, соседние клавиши,
перестановки букв и выученный контекст. Три повторных употребления сочетания
дают контекстное подтверждение; неоднозначные варианты не подменяют текст
автоматически. Это не гарантия безошибочной коррекции и не внешний онлайн-спеллер.

## Изменения

- Старый бинарный IME-обработчик заменён на Java-сервис с проверкой сессии, поля и
  позиции курсора. Отложенная подсказка не может менять другое поле; потеря
  `InputConnection` не приводит к необработанному исключению.
- Набор и обновление курсора не скрывают/не пересоздают клавиатуру. Отдельное поведение
  кнопки B применяется только после явного Enter, в рамках той же сессии.
- Построение словарных индексов, подбор вариантов и обучение работают вне UI-потока.
  Запросы объединяются; незаконченные устаревшие задачи отменяются.
- Опечатки исправляются без пробела после короткой паузы набора. Политика консервативная:
  одна правка, частый однозначный вариант, не корректные слова/префиксы, адреса или пароли.
  Сразу после замены Backspace возвращает исходное слово.
- Частые слова и сочетания изучаются локально. Сохраняются слова/частоты/пары, а не
  полные сообщения. Пароли, чувствительные поля и запрет персонализации исключаются.
- Неоновый интерфейс и пять тем сохранены; добавлены короткие анимации нажатий/переходов.
  Только вкладки «Вид»/«Ввод»: «Отклик», настройки звука и нижний слоган убраны.
- Звук из предоставленного MP3 всегда включён на 50% относительной громкости.
  Системная громкость мультимедиа, тихий режим и DND соблюдаются. Системный звуковой
  режим обновляется по событиям, а не проверяется через Binder на каждой букве.
- Название приложения/IME: **fishka typing**. Карточка канала: **Telegram**.

## Раскладки из интернета

**Языки → Обновить из интернета** загружает небольшой проверяемый JSON-каталог
через HTTPS, сохраняет последнюю рабочую версию и использует её без интернета.
Источник — поддерживаемый каталог проекта на GitHub. При ошибке загрузки
или неверном формате встроенные/сохранённые раскладки остаются доступными.

У APK есть разрешение `INTERNET` только для каталога раскладок. Слова, сообщения,
история буфера и персональный T9 на этот адрес не отправляются. Загрузки идут
в фоне с ограничением размера, таймаутами и проверкой схемы, символов и хоста.
Скачиваются данные раскладок, не программный код.

Каталог сейчас содержит 15 проверенных раскладок; загрузка не превращает их
в поддержку всех языков мира. Каталог можно обновлять новыми лицензированными
раскладками без переписывания обработчика ввода.

## Языки

Показаны 15 действительных нативных раскладок, а не 184 языка с английской подменой:
русский, английский, казахский, украинский, немецкий, французский, испанский,
португальский, турецкий, арабский, болгарский, греческий, иврит, армянский и грузинский.
Казахская раскладка содержит все 42 буквы, включая Ә Ғ Қ Ң Ө Ұ Ү Һ І.
Использованы данные AOSP LatinIME и Keyman; лицензии сохранены в
`assets/KEYBOARD-LAYOUTS-NOTICE.txt` и внутри APK.

Это **не все языки мира** и не CJK-конвертер. Остальные неподдерживаемые варианты не
предлагаются как будто рабочие. Полные частотные словари/автоисправление есть для
русского/английского; в других языках доступны локально выученные слова и подсказки.

## Установка

Пакет остаётся `com.trost.keyboard.restore` ради совместимости с 1.9.2; внутренние
Java-пакеты тоже сохранены для ABI исходного APK. Видимые названия переименованы.
Подпись development-сборки проверяется. При совпадающей подписи APK обновляет 1.9.2
без удаления её данных. Перед любым удалением старого приложения сохраните важную историю.

Сборка тестовая, не production: требуется постоянный защищённый release-ключ.
Приватные ключи не входят в Git или архив исходников.

## Сборка и тесты

```sh
bash android-keyboard/scripts/setup.sh
bash android-keyboard/scripts/test.sh
bash android-keyboard/scripts/build.sh
```

JDK 17, Android SDK API 35 / Build Tools 35.0.0, APKtool 2.12.1, Python 3, zip/unzip.
Инструменты устанавливаются в `.hoplite/android-tools`; разрешены `ANDROID_HOME`,
`JAVA_HOME`, `TROST_KEYSTORE`. APK: `android-keyboard/build/fishka-typing-1.9.4.apk`.

Исходный пользовательский APK 1.8 в `vendor/` содержит Kotlin runtime, Canvas-клавиатуру
и словари. Java-сервис/модели заменяют старые классы. Компиляционные `stubs/` в APK не
включаются. Сохранность отрисовки клавиатуры и верхней панели B проверяется при сборке.

Реальный щелчок извлечён из пользовательского MP3: 0.666667–0.680272 s, stereo PCM16
44.1 kHz. Тембр и скорость не меняются; fade только на границах. Полная запись не
входит в репозиторий. Доступность прав на публичное распространение не подтверждена;
уведомление о происхождении: `assets/SOUND-NOTICE.txt`.

## Android-проверка

```sh
bash android-keyboard/scripts/emulator.sh
adb install --no-incremental --no-streaming -r android-keyboard/build/fishka-typing-1.9.4.apk
adb shell am start -n com.trost.keyboard.restore/com.trost.ioskeyboard.MainActivity
adb shell ime enable com.trost.keyboard.restore/com.trost.ioskeyboard.IosKeyboardService
adb shell ime set com.trost.keyboard.restore/com.trost.ioskeyboard.IosKeyboardService
bash android-keyboard/scripts/build-verification.sh
adb install --no-incremental --no-streaming -r android-keyboard/build/verification/verification.apk
adb shell am instrument -w com.trost.keyboard.verification/.VerificationRunner
```

Тестовый APK отдельно от основного приложения: включает синтетические EditText и
браузерное поле WebView. Проверяет настройки, анимацию, казахский выбор, настоящий
IME-набор, исправление/undo и отсутствие сворачивания в тестовых сценариях.
Это не проверка настоящего monkeytype.com, а браузерного сценария такого же типа.
