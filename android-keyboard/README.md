# trost 1.9.2

Возвращены интерфейс и функции версии 1.9 после регрессии в 1.9.1:

- Неоновый экран настроек, иконки вкладок, карточки тем **Неон / Аметист / Океан /
  Янтарь / Графит**, высота клавиш, размер букв и подсказка при нажатии.
- Динамический локальный T9: частотные словари русского/английского, пользовательские
  слова и сочетания, исправление опечаток в подсказках, продолжения слов и контекст.
  Подсказка вставляется по нажатию; автоматическая замена при наборе по умолчанию выключена.
- Обучение можно отключить. Пароли, чувствительные поля и режим без персонализированного
  обучения исключаются из обучения. Загрузка и сохранение идут в фоне.
- Выбор языка, шифрованная история буфера, вибрация, громкость звука, Telegram-канал.
- Нет «Проверки ввода», онлайн-подсказок и разрешения `INTERNET`.

## Клавиатура и B

Раскладка, нижний ряд, размеры/отрисовка клавиш и верхняя панель взяты из
предоставленного APK 1.8. Обработчик и отрисовка **B не изменены**.
Сборка проверяет сохранность методов рендеринга, верхней панели и обработчиков.
Настройки тем изменяют палитру, но не геометрию клавиатуры.

## Звук из MP3

Вместо синтезированного щелчка используется реальный отрезок предоставленного файла
`u_a4gfvwagf1-iphone-keyboard-typing-sound-effect-336778.mp3`:
0.666667–0.680272 секунды, 44.1 kHz stereo PCM16. Тембр, громкость, высота тона
и скорость не изменяются; небольшой fade только на краях предотвращает артефакты обрезки.
Запись не маркирует действия клавиш, поэтому для букв, пробела и удаления используется
один и тот же исходный щелчок, без выдуманных вариантов.

Исходный MP3 не включён в репозиторий; готовые WAV есть в `res/raw`.
Уведомление о происхождении и правах: `assets/SOUND-NOTICE.txt`.
Доступность прав на публичное распространение записи не подтверждалась.

## Установка

APK — тестовое **отдельное приложение `trost 1.9.2`** (`com.trost.keyboard.restore`),
не обновление поверх прежних APK: их приватные ключи подписи недоступны.
После установки откройте **Включить → Выбрать**. История/настройки старых приложений
автоматически не переносятся, поэтому старую версию с важными данными не удаляйте.

Development-подпись не предназначена для production. Для стабильных будущих обновлений
нужен постоянный защищённый ключ; приватные ключи не добавляются в Git и архив исходников.

## Сборка и тесты

```sh
bash android-keyboard/scripts/setup.sh
bash android-keyboard/scripts/test.sh
bash android-keyboard/scripts/build.sh
```

Используются JDK 17, APKtool 2.12.1, Android SDK API 35 / Build Tools 35.0.0,
Python 3, curl, zip/unzip. Инструменты устанавливаются в `.hoplite/android-tools`.
Скрипт сборки допускает `ANDROID_HOME`, `JAVA_HOME` и `TROST_KEYSTORE`.
Результат: `android-keyboard/build/trost-keyboard-1.9.2.apk`.

В `vendor/` сохранён пользовательский APK с исходным Kotlin runtime и словарями;
Java-замены компилируются через javac/D8, затем применяются проверяемые smali-изменения.
Компиляционные `stubs/` не включаются в APK. Лицензионные уведомления словарей сохранены
внутри исходного APK.

Проверка происхождения WAV и повторное извлечение требуют исходного MP3 и ffmpeg:

```sh
python3 android-keyboard/scripts/extract-clicks.py --source /path/to/original.mp3
python3 android-keyboard/tests/test_audio.py
```

Без исходного MP3 source-provenance тесты явно пропускаются, но готовые WAV и остальные
проверки можно запускать. При проверке этой сборки исходник был доступен и тесты прошли.

## Android-проверка

```sh
bash android-keyboard/scripts/emulator.sh
adb install --no-incremental --no-streaming -r android-keyboard/build/trost-keyboard-1.9.2.apk
adb shell am start -n com.trost.keyboard.restore/com.trost.ioskeyboard.MainActivity
adb shell ime enable com.trost.keyboard.restore/com.trost.ioskeyboard.IosKeyboardService
adb shell ime set com.trost.keyboard.restore/com.trost.ioskeyboard.IosKeyboardService
bash android-keyboard/scripts/build-verification.sh
adb install --no-incremental --no-streaming -r android-keyboard/build/verification/verification.apk
adb shell am instrument -w com.trost.keyboard.verification/.VerificationRunner
```

Verification APK — отдельное тестовое приложение, не пункт меню и не часть основного APK.
Проверяет настройки, переключение темы, вкладки T9/звука и нативную отрисовку исходной
клавиатуры на синтетическом экране; сохраняет свежие изображения Android View.

Каталог ISO 639-1 не является поддержкой всех языков мира. Для отсутствующих нативных
раскладок и CJK-конвертации ограничения указаны рядом с языком. Android ограничивает
чтение буфера: нельзя обещать захват всех копирований вне активного IME.
